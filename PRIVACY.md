# Privacy

Erdvyn Launcher connects to Microsoft and Mojang services for account authentication, Minecraft profile access and game files. It connects to Erdvyn services for account access, server status, launcher updates and managed game files. It also downloads NeoForge from its official distribution service.

Microsoft account data is stored under `%LOCALAPPDATA%\Erdvyn Launcher`. Authentication data is encrypted with Windows Data Protection API and can be removed by signing out.

Game files, settings and launcher logs remain on the local computer. The launcher does not upload local files or logs automatically.

Network requests occur only for launcher functions selected by the user or required to start and update the managed game installation.
